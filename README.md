# SWYNEX Interactive Dashboard

## Project Overview
This project presents an interactive Superstore Sales and Profit Dashboard developed using Microsoft Power BI Desktop as part of **SWYNEX Internship – Task 3**.

The dashboard helps analyze sales performance, profitability, product categories, customer segments, and regional sales.

## Objectives
- Analyze overall sales and profit performance.
- Compare sales across different regions.
- Identify the most profitable product categories.
- Compare sales across customer segments.
- Enable interactive analysis using slicers and filters.

## Tools Used
- Microsoft Power BI Desktop
- Superstore dataset
- Data visualization and exploratory analysis

## Dashboard Features
- **Total Sales:** Displays overall sales.
- **Total Profit:** Shows the total profit generated.
- **Profit Margin:** Highlights profitability as a percentage.
- **Sales by Region:** Compares sales across regions.
- **Profit by Category:** Compares profitability across product categories.
- **Sales by Segment:** Compares sales across Consumer, Corporate, and Home Office segments.
- **Interactive Filters:** Allows users to filter the dashboard by Region, Category, and Segment.

## Key Insights
- Technology is the most profitable product category in the dashboard.
- Office Supplies also contributes substantially to total profit.
- Furniture generates considerably less profit than Technology and Office Supplies.
- The Consumer segment contributes the highest sales among the customer segments.
- Regional sales vary, allowing performance comparisons across the four regions.
